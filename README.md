# cloudyv

**Cloudy Tone** is a creator and model portfolio based in Mirzapur. Visitors can browse an introduction to the creator, services, selected work, and collaboration information, along with contact or booking sections.

## Preview locally

Open `index.html` in a modern browser, or serve the project folder over HTTP:

    python -m http.server 8000

Then visit http://localhost:8000.

## Updating the portfolio

The main page is `index.html`. Keep the About, Services, Work, and Collaboration sections current, and verify contact and booking links before publishing.
