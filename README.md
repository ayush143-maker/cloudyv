# cloudyv

**Cloudy Tone** is a creator and model portfolio based in Mirzapur. The portfolio is a single HTML page in `index.html`, where visitors can browse an introduction to the creator, services, selected work, and collaboration information, along with contact or booking sections.

## Preview locally

Open `index.html` in a browser, or serve the project folder over HTTP:

    python -m http.server 8000

Then visit http://localhost:8000. After editing the page, reload it and review the portfolio sections and any updated contact or booking links.

## Updating the portfolio

Keep the About, Services, Work, and Collaboration sections current in `index.html`, and verify contact and booking links before publishing.
